# Prominence 2 RPG (Russian Localization)
## Информация

Русификация модпака **Prominence 2 RPG: Hasturian Era**.

Оригинал модпака можно найти по [ссылке](https://www.curseforge.com/minecraft/modpacks/prominence-2-rpg).

## О локализации

Перевод корректно работает на лаунчерах [**CurseForge**](https://www.curseforge.com/download/app), [**Prism Launcher**](https://prismlauncher.org/download/windows/) и [**Modrinth**](https://modrinth.com/app).

Благодаря новому подходу (мод + внешние файлы перевода) локализация **совместима с любой версией сборки**: обновления модпака больше не ломают перевод.

### ⚠️ Почему нет официальной локализации?

Мы пытались договориться с автором модпака о добавлении русского перевода в оригинальную сборку, но получили отказ: спонсоры проекта не работают на территории России. Поэтому перевод распространяется отдельно.

### 🔧 Установка

1. [**Скачать последний релиз**](https://github.com/d0ukesh1/Prominence-2-RPG-Russian-Localization/releases) перевода.
2. Скопировать с заменой файлы в корневую директорию модпака. (Например, **C:\Users\USERNAME\curseforge\minecraft\Instances\Prominence II RPG Hasturian Era**)
3. Запустить игру и наслаждаться!

### 🛠️ Требуемый мод: Prominence Localization

Для работы перевода необходим мод **Prominence Localization** (идёт в комплекте с релизом, лежит в папке `mods/`).

**Что он делает:**
- Принудительно устанавливает русский язык в игре
- При запуске сканирует файлы конфигурации FancyMenu, FTB Quests и других модов
- Применяет замены по словарю из файлов перевода
- Работает до загрузки других модов — поэтому к моменту отрисовки интерфейса текст уже переведён

**Настройка:**
- Конфигурация лежит в `config/prominence_localization/config.json`
- Файлы перевода — в `config/prominence_localization/lang/ru_ru/` (по одному JSON на каждый модуль)
- В `config.json` можно указать целевой язык и список директорий для сканирования
